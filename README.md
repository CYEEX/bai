# 掰

掰 — 猜角度的派对游戏

用 MacBook 的屏幕开合角度出题，和朋友一起比眼力。

## 打开与游玩

双击「掰.app」。Apple Silicon Mac、macOS 14 或更新系统；需要能通过 HID 读取的屏幕角度传感器。兼容性按实际检测结果判断，不能只根据芯片推断。

1. 填写 2–8 位玩家昵称，点击「双人」或「三人」快速选人数，再选择「3 轮」或「5 轮」（默认 3 轮，也可用 ± 调整至 1–10 轮），点击「开一局」。
2. 把屏幕随手调到一个位置。等「已稳定，可以锁定」出现后，点击「就这个角度」。
3. 每个人观察同一个角度，输入 0–180 的整数，再点「我猜好了」。回车也能提交；− / ＋ 每次调整 1°。
4. 交给下一位时，先前答案会隐藏。保持屏幕原位，直到全员提交。
5. 点击「揭晓答案」一起看结果。平均绝对误差越小，最终排名越高；相同误差并列。

屏幕合上时为 0°，垂直于键盘时为 90°。只在正常铰链范围内调整，输入允许到 180° 不表示电脑能开到 180°。

锁定后偏离超过 2° 并持续半秒，本轮自动作废并清空答案。读数中断超过 0.75 秒、电脑或显示器睡眠，也会使未揭晓的本轮作废。已揭晓轮次不受影响。重新稳定后可继续本场比赛。

昵称最多 12 个字符；空昵称自动使用「玩家 N」。比赛仅保存在内存，关闭应用或结束比赛后清空。应用不联网，不上传数据，不请求屏幕录制、摄像头或辅助功能权限。

窗口支持缩放与 macOS 全屏；内容较多时可以滚动。系统开启「减少动态效果」时，揭晓不播放过渡动画。

## 外观与图标

右上角「外观」可选择浅色、深色或跟随系统。默认跟随系统，手动选择会记住到下次启动。应用图标来自用户提供的原图，提取中间圆角矩形本体，保留图内像素与比例，外部背景透明。Dock 图标使用系统原生 Icon Composer 格式，圆角由系统统一生成。

## 嘎吱音效

屏幕移动时会播放从你本机 LidAngleSensor 提取的原版门轴声，快慢随移动速度变化；停手后约 0.12–0.15 秒内收声。页脚「嘎吱音效」可随时开关，默认开启。音高与音量只取决于移动速度，不编码绝对角度。演示模式不播放，休眠和读数断开时立即静音。使用原版门轴音频，来源记录见第三方说明；不需要麦克风权限。

## 演示模式

开局页右下角可选择「体验演示模式」，会在页脚持续标明。虚拟角度每轮随机产生，**不反映真实屏幕位置**，只用于体验多人交接和排名流程。只能在开局页切换模式，避免混用真实与虚拟成绩。

## 传感器无法连接

点击「重新检测」。直接从 Finder 打开应用，避免在受限制的开发沙箱中运行。若仍未找到，可能是机型或系统接口不兼容；使用演示模式可查看流程。

本机签名（ad-hoc），未经过 Apple 公证。应用若在另一台 Mac 被系统阻止，可先移到「应用程序」，尝试右键打开；如系统仍阻止，按「系统设置 → 隐私与安全性」中针对该应用的提示处理。只打开你信任的这份构建，不需要关闭系统安全功能。

## 源码与构建

需要完整 Xcode。无第三方包依赖；构建目标为 arm64、macOS 14+。

```sh
bash test.sh
bash build.sh
```

应用输出到 `dist/掰.app`。也可 `bash build.sh /绝对路径/输出目录`。

命令行硬件诊断（5 秒；不启动游戏）：

```sh
./dist/掰.app/Contents/MacOS/AngleParty --diagnose
```

`--demo` 参数以演示模式打开应用。正式应用默认始终使用真实传感器，不会静默切换到虚拟数据。

- `Sources/GameEngine.swift`：稳定窗口、中位数锁定、多人流程、误差、排名、失联与移动作废。
- `Sources/Sensor.swift`：后台串行 HID 读取与显式演示数据源。
- `Sources/GameSession.swift`：界面状态、采样时间检查、睡眠恢复。
- `Sources/ContentView.swift`：黑橙配色的原生 SwiftUI 界面。
